# Corpus classement-bruite

Corpus R2 entièrement synthétique : texte OCR volontairement bruité, dates historiques et dates de naissance sans personne identifiée. Les seules raisons sociales sont des organisations suisses génériques autorisées. `verite.json` est l'oracle ; les réponses IA y sont simulées afin que la porte ne dépende ni du réseau ni d'une donnée réelle.
